# Smart Temperature Monitoring System (C++)

This project is a simulation of a temperature monitoring system developed in C++. It demonstrates basic automation logic by analyzing sensor data and triggering alerts when values exceed defined limits.

## Features
- Simulates temperature sensor readings
- User-defined minimum and maximum thresholds
- Detects high and low temperature conditions
- Displays monitoring results in real time

## Technologies
- C++

## How it works
The program generates random temperature values and compares them to user-defined limits. If the temperature goes beyond these limits, the system displays an alert.

## How to run

Compile:
g++ main.cpp -o monitor

Run:
./monitor

## Purpose
This project was created to strengthen understanding of programming logic, conditions, loops, and basic monitoring systems used in automation.
